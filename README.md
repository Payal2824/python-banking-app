# Python Banking Application

A simple console-based banking application developed using Python.

## Features

- Create a bank account
- User login with account number and PIN
- Deposit money
- Withdraw money
- Check account balance
- Transfer money between accounts
- Logout

## Technologies Used

- Python 3
- Git
- GitHub
- Docker
- GitHub Actions

## How to Run

Clone the repository:

```bash
git clone <repository-url>
```

Go to the project directory:

```bash
cd python-banking-app
```

Run the application:

```bash
python3 main.py
```
